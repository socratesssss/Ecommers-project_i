# 🛒 E-Commerce Website (Frontend)

A responsive and modern **e-commerce web application** where users can browse products, view details, select variants, and place orders. Built using **React**, **TypeScript**, and **Tailwind CSS**, and powered by an Express-based backend.

---

## ✨ Features

- 🛍️ View all products by category
- 🔍 Filter by price, category, and sort order
- 🎨 Select color and view related images
- 📦 Product details with pricing & discount logic
- 🛒 Add to cart with quantity controls
- 🧾 Place orders with delivery info & payment method
- 🖼️ Mobile and desktop image carousels
- 📱 100% responsive on all devices
- 🔁 Data fetched dynamically from backend API

---
